One line: the out-of-office auto-reply a houseplant would send.

> I am out of office until someone waters me. My last drink was in March. Please send sunlight, not meetings.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python 3.13 standard library and writes the entry to `/output/entry.txt`.
